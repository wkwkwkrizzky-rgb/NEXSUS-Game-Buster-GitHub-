NEXSUS GAME BUSTER — SOURCE PROJECT

Isi:
- Daftar aplikasi yang bisa diluncurkan dari perangkat.
- Preset sensitivitas berupa panduan (tidak mengubah pengaturan internal game).
- Rekomendasi grafis LOW / BALANCED / ULTRA.
- Informasi RAM dari Android.

PENTING:
Proyek ini adalah SOURCE PROJECT Android Studio, bukan APK siap-install.
Untuk membuat APK:
1. Buka folder proyek di Android Studio.
2. Tunggu Gradle selesai melakukan sinkronisasi (memerlukan internet saat pertama kali).
3. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK biasanya muncul di app/build/outputs/apk/debug/app-debug.apk.

Aplikasi tidak dapat membersihkan RAM secara paksa, menaikkan FPS secara ajaib,
atau mengubah sensitivitas/grafik di dalam game lain. Android dan masing-masing
game membatasi akses tersebut. Fitur di aplikasi ini dibuat sebagai pintasan,
informasi, dan panduan yang aman.
